# 知新 · 新概念英语学习室

中文英语学习网站，原生 HTML/CSS/JavaScript，无需构建或数据库。

## 本地运行

安装 Node.js 后，在此目录运行 `node serve.cjs`，打开 http://127.0.0.1:4173。

本次功能分支也可运行 `npm start`，打开 http://127.0.0.1:4178；预览服务器只监听本机。稀疏源码副本中未包含的 PDF、音频会跳转原公开站点获取。运行 `npm test` 检查造句规则、草稿交互和词典适配。

## 新增练习与查词

- 在“输出训练 → 五句造句”中，每个目标词分别写肯定句、否定句、一般疑问句、特殊疑问句和旧知综合句。第五句加入一个不同的旧词及旧用法，显示来源课次。
- 有学习记录的早期课程自动提供旧知；也能明确勾选以前学过的课程。草稿按课和单词保存，切词、切模式和刷新后可恢复，随学习数据备份。
- 检查仅覆盖有限结构与基本要求，不判断完整语义、自然度或四句是否完全对应，也不会自动计分或标记掌握。
- 点击课文单词，立即显示本地中文释义并自动查询 Free Dictionary API 英文释义。仅所点单词发送到该服务；已有草稿、学习记录不会发送。在线失败仍保留本地内容，可选重试或打开有道中英词典。更换词或关闭弹窗会取消旧查询。

## 当前内容

- 四册入口；主学习单元仅取自用户提供的新概念课堂笔记，未接入的册次明确留空，不以原创短文代替教材。
- 点词发音、生词本、习惯用法、语法与词汇题、听写、学习记录。
- 来源笔记分课阅读、每单元重点知识/语法/习惯用法、分段默写、单词拼写、英文复述关键词反馈。
- 基于真实单元的精选关卡，每关5题，星级、XP、每日目标和徽章；缺资料的册次不开放假关卡。
- 单词点读使用已有词音频或设备英语语音；整课已接入 NativeEars 第二册96课、第三册60课、第四册48课音频，来源可在播放器旁查看。
- 默写和复述支持本地基础语法检查、逐项修改与全部应用；属于规则检查，不能判断表达是否完整或覆盖全部语法问题。
- 10份用户资料已转换为384个文字小节，保留全部50730条非空文字行；原PDF仅为可核对的次要下载入口。原资料共1468页，范围为第一至第三册及通用练习。尚未获得完整四册教材英文原文、第四册笔记或原版音频。
- TXT/LRC/JSON与自有音频本地导入；学习数据JSON备份和生词CSV导出。

## 数据

个人进度、生词本与自行导入的资料保存在当前浏览器；不会上传给网站或分享给其他访问者。文件音频存储在IndexedDB。跨设备可导出并恢复JSON备份，音频需各设备单独导入。

## 第三册与第四册音频

接入用户提供的 NativeEars 第三册60课和第四册48课音频目录，音频以本站MP3播放，支持现有进度、倍速与循环。已有笔记和正文沿用原课程ID；其余课程标明“仅音频 · 正文资料待补充”，不生成假正文或题目。音频按钮旁保留每课原始来源链接。第二册96课音频保持原有映射。

来源：[第三册系列48](https://nativeears.mojoru.org/series/48)、[第四册系列47](https://nativeears.mojoru.org/series/47)。新增108个MP3逐个校验来源字节数、SHA256和有效MPEG帧；目录见 nativeears-advanced-catalogue.js。dev/fetch_nativeears_advanced.py 可用来源目录快照重新下载并生成目录。
