# 每日任务与输出复习

学习页的今日任务先安排最多三张到期卡，再安排一个单词或习惯用法的五句输出、一个语法自我讲解和课文文字复述。当天清单固定，浏览其他课不会更换任务；可以明确选择当前课重新安排。缺少已核对词义或语法资料的课，不生成对应任务。

五句可以模仿可靠例句，变换人物、时态、时间地点和语境；也可切换到原有的句型变换模式。旧草稿保留，每日新轮另存。语法讲解先写自己的理解、判断依据和例句，再按需要查看参考。

参考课堂笔记中的每词五句、自我讲解、每个习惯用法五句及 Tell the story：[第二册笔记，第8、10–12页](../resources/eef57c5b3d1610c5.pdf#page=8)。课程结构也可见[胶学的新概念课程](https://www.bilibili.com/video/BV1zY4y187cK/)。本工具独立制作。

查看答案、原文或修改建议会记录辅助标记。只有独立且客观答对的卡片才能延长间隔；造句、讲解、文字复述记录输出，不代表语义、完整语法或口语质量已经通过。1、3、7、14、30天是网站的复练安排，使用提示后会提前复练，并非老师指定的日程。

数据保存在当前浏览器，备份包含新任务与草稿。跨设备需要导出并恢复学习备份；没有后台自动同步。新任务不会更改正式测验成绩，标记已读也不等于掌握。
